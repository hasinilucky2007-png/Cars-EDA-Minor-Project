# 🚗 Exploratory Data Analysis on Cars Dataset

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on a used cars dataset to understand car pricing patterns, vehicle characteristics, and relationships between different features.

## 🎯 Objectives
- Understand the structure of the dataset.
- Identify and handle missing values and duplicate records.
- Perform descriptive statistical analysis.
- Visualize important patterns and relationships.
- Identify key factors associated with car selling prices.

## 📂 Dataset
**Source:** [Vehicle Dataset from CarDekho – Kaggle](https://www.kaggle.com/datasets/nehalbirla/vehicle-dataset-from-cardekho)

The original dataset contains 8,128 records and 13 columns.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## 🧹 Data Cleaning
- Removed duplicate records.
- Extracted numerical values from mileage, engine, and max power.
- Handled missing values.
- Identified invalid zero values.
- Extracted car brands from vehicle names.

## 📊 Exploratory Data Analysis
The project includes:
- Car brand distribution
- Fuel type distribution
- Selling price distribution
- Year vs. selling price
- Kilometers driven vs. selling price
- Average price by transmission
- Correlation heatmap
- Outlier analysis

## 🔍 Key Findings
- Maruti is the most frequently occurring brand.
- Diesel cars form the largest fuel category.
- Manual transmission cars are more common.
- Maximum power has the strongest positive correlation with selling price among the numerical features analysed.
- Selling prices show considerable variation.
